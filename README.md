# Universal Form Validator

A lightweight, zero-dependency JavaScript library designed to solve the repetitive task of writing form validation rules. 

- **Framework Agnostic:** Works in React, Angular, Node, or Vanilla JS.
- **Zero-JS Mode:** Use HTML data attributes for instant validation on WordPress or static sites.
- **Secure:** Built-in sanitization rules for baseline security.

*Documentation and installation guide coming in v1.0.0.*
